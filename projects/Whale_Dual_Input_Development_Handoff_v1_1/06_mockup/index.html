화면 상태 시연

이 화면은 시각 디자인 테스트용입니다. 오른쪽 선택 메뉴와 ON/OFF 버튼은 실제 전자칠판·교사 마우스를 제어하지 않습니다.

실제 제품에서 중요: 상태는 사용자 선택이나 오래된 저장 값이 아니라 Windows 입력 격리의 실시간 증거와 Whale 어댑터 연결을 확인해 결정합니다. 교사 포커스 보호가 입증되기 전에는 ACTIVE로 표시하면 안 됩니다.
