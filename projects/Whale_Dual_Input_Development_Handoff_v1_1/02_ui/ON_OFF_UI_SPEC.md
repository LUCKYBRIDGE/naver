# 웨일 듀얼 인풋 — 사이드바 ON/OFF UI 상세 명세 v1.1

> **목표:** 교사가 전문 용어를 모르더라도 설치 후 **ON/OFF 두 동작 중심**으로 운용한다.  
> **제품 UI 형태:** 기존 GitHub `manifest.json`의 `sidebar_action`을 우선 유지한다. `action`과 동시 선언하지 않는다.  
> **확인 시점:** 2026-10-08 GitHub manifest v0.2.0에 `sidebar_action.default_page=sidebar/sidebar.html` 확인.  
> **중요:** 아래 모형은 목표 화면이지 지금 구현돼 있다는 의미가 아니다.

## 2. 정보 계층과 구성요소

| 우선 | 요소 | 규칙 |
|---|---|---|
| 1 | 제품명 + 간결 설명 | `웨일 듀얼 인풋` / `전자칠판 학생 독립 터치` |
| 2 | 보호 및 작동 상태 | 최상단. 색상 + 아이콘 + **텍스트** 동시 표시. 실제 보호 상태 기반 |
| 3 | 모니터 / 터치 장치 / 학생 웹 연결 | 짧은 3행. 값은 진짜 연결·ACK 데이터 기반, 추정·가짜 초록 체크 금지 |
| 4 | 주 행동 버튼 1개 | OFF이면 `학생 독립 터치 켜기`, ACTIVE이면 `끄기` |
| 5 | 보조 행동 | ACTIVE일 때 `교사 일시 해제`, PAUSED에서 `다시 켜기`, 장애에서 `다시 확인` 등 |
| 6 | 상태별 주의/복구 문구 | 안전 영향, 해결 방법을 사용자 말로 안내 |
| 7 | 진단 펼치기 | 기술적 오류·연결 테스트·진단 복사. 개인정보 최소화 |

**디자인 철학:** 버튼 하나가 주 행동. 기존 학생 사이트의 화면을 조작하기 위해 교사에게 칠판을 터치하도록 요구하지 않는다. UI는 교사의 실제 마우스로 조작한다.

## 3. 전체 상태별 UI·주 행동 명세

| 기술 상태 | 사용자 표시 제목 | 설명 | 주 행동 | 보조 행동 | 안전 의미 |
|---|---|---|---|---|---|
| `OFF` | 독립 터치 꺼짐 | 전자칠판은 일반 Windows 터치 상태입니다. | 학생 독립 터치 켜기 | 진단 보기 | 학생 입력 격리 X |
| `DISCOVERING` | 화면과 터치 확인 중 | 모니터 2와 연결된 터치 장치를 자동으로 찾습니다. | 진행 표시(비활성) | 취소(안전 복구 확인 시) | 보호 완료 아님 |
| `PREPARING` | 독립 입력 준비 중 | 입력 격리와 웨일 연결을 확인합니다. | 진행 표시(비활성) | 취소(정리 완료 후) | 보호 완료 아님 |
| `ACTIVE` | 학생 독립 터치 작동 중 | 학생 터치는 웨일 웹페이지로 전달되고 교사 입력은 분리됩니다. | 끄기 | 교사 일시 해제 | 격리 ACK + 어댑터 정상 확인 |
| `PAUSED_BY_TEACHER` | 교사 일시 해제 중 | **전자칠판이 일반 Windows 터치로 돌아왔습니다.** 학생 터치가 교사 작업에 영향을 줄 수 있습니다. | 독립 터치 다시 켜기 | 완전히 끄기 | 격리 X, 교사의 의도적 해제 |
| `SAFE_HOLD` | 학생 입력 연결이 일시 중단됨 | 격리는 유지되지만 학생 웹 조작은 잠시 멈췄습니다. | 다시 연결 확인 | 끄기 | 격리 생존 관측시에만 표시 |
| `LOST_PROTECTION` | 입력 보호가 중단되었습니다 | **전자칠판을 터치하면 교사 커서가 움직일 수 있습니다.** 터치를 멈추고 복구 상태를 확인하세요. | 보호 다시 설정(조건 충족 시) | 안전하게 종료 / 복구 안내 | ACTIVE 절대 금지 |
| `UNSUPPORTED` | 이 환경에서는 켤 수 없습니다 | 아래 이유를 확인하고 해결한 뒤 다시 시도하세요. | 다시 확인 | 해결 방법 | ACTIVE 불가 |
| `INSTALL_REQUIRED`(UI 사유) | Windows 구성요소 설치 필요 | 최초 1회 설치해야 전자칠판 터치를 분리할 수 있습니다. | 설치 방법 보기 | 다시 확인 | Native 연결 없음 |

`INSTALL_REQUIRED`는 실제 입력 상태 머신을 새로 만들기보다 `OFF/UNSUPPORTED + reason=NATIVE_MISSING`의 **화면 표현**으로 구현하는 것을 권장한다.

### 상태 표기 엄격 규칙

1. `ACTIVE`는 Native 격리 ACK, 보호층 실시간 생존 증거, 모니터 장치 매핑, Whale Web Adapter 연결이 **모두 유효**할 때만.
2. `SAFE_HOLD`는 격리층이 실제 계속 작동하는 것으로 확인된 경우에만.
3. `LOST_PROTECTION`은 복구 버튼이 있어도 실제 재격리가 확인되기 전까지 그대로.
4. `PREPARING`에서 `OFF`로 즉시 표시해도 되는 것은 실제 원본 입력 정리/해제 완료 이후.
5. 새로고침·사이드바 닫았다가 열기·MV3 Worker 재시작 뒤에도 **실제 Native 상태를 다시 읽는다**. `storage`의 마지막 문자열만 믿지 않는다.
6. 마우스 2 화면 표시가 보인다는 이유만으로 `ACTIVE` 선언 금지.

## 4. 에러 사유 코드 → 사용자 메시지

| reasonCode | 사용자 문구 | 다음 행동 |
|---|---|---|
| `NATIVE_MISSING` | Windows 구성요소를 찾을 수 없습니다. | 설치 안내 열기 / 다시 확인 |
| `DISPLAY_NOT_EXTENDED` | 화면 복제 중입니다. Windows에서 **화면 확장**으로 바꿔 주세요. | Windows 디스플레이 설정 안내 |
| `MONITOR2_MISSING` | 두 번째 화면이 연결되지 않았습니다. | 케이블/Windows 화면 연결 확인 |
| `TOUCH_MAPPING_INVALID` | 터치 장치가 2번 화면에 연결된 것으로 확인되지 않습니다. | Windows 터치 화면 설정 안내 |
| `TOUCH_MAPPING_AMBIGUOUS` | 어느 장치가 전자칠판인지 자동 판정할 수 없습니다. | 연결 점검/진단 |
| `OTHER_TOUCH_DEVICE` | 다른 터치 화면도 연결되어 있어 안전한 분리가 어렵습니다. | 지원 조건 안내, 임의 격리 금지 |
| `MOUSE_EMULATION_UNSUPPORTED` | 이 장치는 터치를 마우스 신호로 전달하여 현재 방식에서 지원되지 않습니다. | 입력 모드 확인/진단 |
| `ISOLATION_UNAVAILABLE` | 이 PC에서는 독립 입력 보호를 시작할 수 없습니다. | 기술/정책/설치 안내 |
| `POLICY_BLOCKED` | Windows 또는 학교의 보안 정책으로 실행할 수 없습니다. | 관리자 안내 |
| `REDIRECTION_CONFLICT` | 다른 프로그램이 터치 입력을 사용 중입니다. | 충돌 진단 / 강제 탈취 금지 |
| `WHALE_ADAPTER_UNAVAILABLE` | 웨일 웹페이지 연결을 확인할 수 없습니다. | 모니터 2에서 웨일 웹페이지 열기 / 다시 확인 |
| `CDP_CONNECTION_FAILED` | 웹페이지 입력 연결에 실패했습니다. | 디버거 충돌·권한 도움말 |
| `BRIDGE_DISCONNECTED` | 웨일과 Windows 프로그램 연결이 끊겼습니다. | 실제 격리 확인 후 SAFE_HOLD/LOST_PROTECTION 분기 |
| `PROTECTION_LOST` | 입력 보호가 중단되어 전자칠판 터치가 교사 작업에 영향을 줄 수 있습니다. | 터치 중단/복구 안내 |
| `UNSUPPORTED_TARGET` | 이 화면은 학생 독립 터치를 지원하지 않습니다. | 웨일 일반 웹페이지로 이동 |

**문구 규칙:** 상태를 단순히 '오류'로 뭉뚱그리지 않는다. `LOST_PROTECTION`에서는 '안전하게 보호 중' 문구를 쓰지 않는다. 화면 복제 모드에서는 임의의 화면을 자동 선택하지 않는다.

## 5. 화면 상호작용 상세

### 5.1 ON 동작

1. 교사가 확장 사이드바에서 `학생 독립 터치 켜기` 클릭.
2. UI 즉시 `DISCOVERING`으로 바꾸고 **요청 중** 표시(버튼 중복 방지).
3. Windows Native Bridge의 살아 있는 연결 확인. 없으면 원인을 표시하고 ON 종료.
4. 확장 모드/모니터 2/장치 매핑/격리 타입/정책 확인.
5. 학생 웨일 창과 활성 탭 식별, CDP 세션 준비. 포커스 탈취 없이 처리 가능한지 확인.
6. 격리 C2 활성, 격리 생존/장치 매핑 ACK 확인. 버튼·접촉 상태 epoch 초기화.
7. 모든 필수 조건 충족하면 `ACTIVE`. 실패하면 C2 보호 상태에 맞춰 `SAFE_HOLD`/`LOST_PROTECTION`/`UNSUPPORTED`, 상세한 원인과 교사 복구 방법 표시.
8. **입력 처리가 검증되지 않은 상태에서 활동할 수 있다는 가짜 성공 안내 금지.**

### 5.2 OFF 동작

1. 사용자가 `끄기` 클릭. 미완료 접촉/버튼 상태 `CANCEL` 및 해제.
2. 학생 CDP 전달 중지·세션 정리; 큐 버전 갱신.
3. 원본 격리 해제 요청과 **실제 OFF ACK** 확인.
4. 그 후 `OFF`로 표시; 불확실하면 경고·복구 안내.

### 5.3 교사 일시 해제

- ACTIVE에만 노출. 클릭 직후 '전자칠판 터치가 일반 Windows 터치로 돌아갑니다. 학생이 터치하면 교사 커서/포커스에 영향을 줄 수 있습니다.' 확인 대화상자 제공(기본 행동은 취소).
- 확인 후 안전한 종료 시퀀스로 격리 해제 → `PAUSED_BY_TEACHER`로 표시.
- `독립 터치 다시 켜기`는 단순 숨김 해제가 아니라 ON 선행검사와 격리 ACK를 재수행.

### 5.4 연결 장애와 복구

- 일반적인 웹 입력 어댑터 연결 단절 + 격리 생존 ⇒ `SAFE_HOLD`. 자동 재연결 시도, 교사에 `다시 연결 확인` 제공. 보호 유지 중 학생 터치는 조작에 반영되지 않을 수 있음.
- 격리 프로세스·등록·장치 보호 자체 소멸 ⇒ `LOST_PROTECTION`. **위험 경고 우선**. 그 순간의 보호 공백을 watchdog으로 소급 없앨 수 없음.
- 장치가 모호한 상태에서 `다시 확인`으로 다른 장치를 임의 선택하거나 일반 OS 입력을 자동 주입하지 않는다.

### 5.5 진단 상세 패널

접힌 영역: Windows 구성요소 연결, 디스플레이 식별, 터치 분류 결과(PT_TOUCH/PT_PEN/PT_MOUSE), 격리 Tier A/B/미선택, 버전, 어댑터, 최근 오류 코드(입력값·URL 제외), 마지막 상태 갱신 시각, `진단 정보 복사`.

**민감 데이터 비수집:** 장치 경로 전체·학생 타이핑·URL·문서 제목·성명은 기본 화면/복사에서 제외. 개발자 모드는 별도 명시적 동의와 저장 기간 정책이 필요.

## 6. 접근성 및 조작 기준

- 화면은 **사이드바 폭 약 320–400 CSS px**부터 사용. 320 이하에서도 가로 스크롤/버튼 겹침이 없도록 한다.
- 터치 가능한 버튼 높이 44 CSS px 이상, 키보드 Tab으로 전 요소 접근, 상태 변경은 `aria-live=polite`를 사용하고 보호 상실은 `role=alert`.
- 색상만으로 구분하지 않고 `작동 중/중단/보호 상실` 텍스트+아이콘 제공.
- 로딩 애니메이션은 `prefers-reduced-motion`을 존중.
- 사이드바를 닫아도 실행 엔진 유지. 단 **현재 상태 화면이 닫혔다고 실제 보호가 사라지면 안 된다.** 재오픈 때 Native의 권위 있는 상태 조회.

## 7. 범위 외

- 브라우저 바깥에 항상 표시하는 전역 ON/OFF 플로팅 버튼, 원래 웨일 크롬 UI 독립 터치, 모든 Windows 앱 입력 자동 지원.
- 화면 좌표를 드래그하거나 직접 입력하는 설정, 제조사별 모델 선택.
- 모니터 1의 교사 마우스를 고정하거나 특정 영역 출입을 막는 기능.
- `UI 데모`를 실제 활성화된 것처럼 포장하는 출력.

## 8. 구현 인계 체크
