# 개발 완료 판정 · 테스트 계획 (G1 우선)

> 이 파일은 시험 **계획**이다. 실제 시험 수행/통과를 의미하지 않는다. 사용자 PC·전자칠판에 접근해 실측한 결과는 별도 `TEST_REPORT`에 기록한다.

## 0. 공통 수칙

- 보호가 실제 작동하지 않는 상태에서 학생들에게 '안전하게 분리됐다'고 안내하지 않는다.
- **수동 사각형 영역 드래그/좌표 보정/UI 사이트 등록이 추가되면 UX 실패**.
- 교사의 실제 마우스가 모니터 2 위에 있을 때도 정상 사용 가능해야 한다.
- `npm test`, `npm run build` 성공은 Windows 실기기 G1 PASS가 아니다.
- 테스트 PC의 계정·문서·네트워크 권한을 안전하게 제어하고 로그에 학생 타이핑·URL·문서 제목을 남기지 않는다.

| ID | 시험 | 합격(정상 ACTIVE 시) |

| G1-04 | 교사 마우스 이동과 칠판 멀티터치 동시 | 장치별 이벤트 분리, 교사 포커스 무간섭 |

| G1-06 | 물리 터치의 `WM_MOUSE`/호환 이벤트 관측 | 격리 성공 중 커서·포커스 오염 없음 |
| G1-07 | 교사 터치 노트북/터치 모니터 동시 연결 | Tier A의 전역 타입 격리 범위 자동 판정; 지원 불가면 ON 금지 |
| G1-08 | 강제 종료·watchdog·잠금/UAC 시험 PC 시험 | Tier A 보호 공백과 실제 커서 영향을 계측해 그대로 보고; PASS라고 숨기지 않음 |

**양성 대조군:** 격리 OFF에서 실제 터치가 교사 커서에 미치는 영향을 관측할 수 있는지 먼저 확인. 검출에 실패하는 로거에서 나온 G1=0은 증거가 아니다.

## 4. 운영·설치·저작권·보안

- `SEC-01`: 기존 `sidebar_action` 기반으로 작동, `action` 동시 선언 금지.
- `SEC-02`: Native Messaging 확장 허용 ID 제한; 브리지 인증·로컬 IPC ACL 검증.
- `SEC-03`: 학급 활동 URL·학생 글자·교사 문서 제목을 기본 로거에 저장하지 않음.
- `SEC-04`: Microsoft UIAccess 접근성 목적·정책/서명 판단 문서화, 미해결 시 Tier A 제품 배포 금지.
- `SEC-05`: Tier B 드라이버(사용 시) 서명·HVCI·제거·롤백·안전 복구 점검.
- `SEC-06`: 다른 제조사의 **표준 입력 장치** 최소 2종 이상에서 동일 코드 경로 시험; 실패 유형 명시.
- `SEC-07`: MouseMux MIT SDK 예제는 참고만; 라이선스 미확인 Chrome 패치나 상용 드라이버 바이너리 번들 금지.
- `SEC-08`: 인터넷 연결 없이 핵심 입력 기능 실행(Whale 웹페이지 자체의 네트워크 필요와 구분).

## 5. 성능 목표 — 측정 전 보장 금지

- Native 격리 이벤트 → 어댑터 전달 p50 ≤10ms, p95 ≤25ms 지향(실측 전 목표).
- Windows 원래 터치 대비 웹 렌더링 **추가 지연** 약 1프레임(60Hz 16.7ms) 이내 최적화 목표(실측 전 미확정).
- p50/p95/p99, 각 입력 이벤트 손실, 멀티터치, 교사 동시 작업, 저사양 PC, 고부하 상태 별도 기록.
- 정확성 판정 로거가 지연을 만들 수 있으므로 성능 시험은 측정 방법을 분리.

## 6. 출시 차단(NO-GO)

1. ACTIVE 시 학생 터치가 교사 커서·키보드 포커스를 건드리는 경우.
2. 물리 입력 C2 격리가 없이 CDP/화면 가상 커서만 보여주는 경우.
3. UIAccess 기술/정책 미검토, 또는 서명하지 않은 드라이버를 학교에 임의 설치하려는 경우.
4. 화면/터치 장치/Whale 어댑터 상태가 미확인인데 ACTIVE라고 표시하는 경우.
5. 교사에게 수동 사각형·영역 드래그·웹사이트마다 URL 지정·커서 복원을 강요하는 경우.
6. 종료 또는 분리 실패 시 학생 입력이 교사 작업에 영향을 줌에도 화면에서 위험을 감추는 경우.
7. Whale 외 모든 Windows 앱 조작이 가능하다고 성과를 과장하는 경우.
