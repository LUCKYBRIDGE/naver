# 제품 범위 및 사용자 스토리 — Whale Dual Input v1

## 1. 한 문장 정의

교사가 한 대의 Windows PC에 연결한 **모니터 2 전자칠판에서 학생이 웨일 웹페이지를 독립 터치**할 수 있도록, 터치 장치의 원본 입력을 교사 Windows 커서·포커스에서 격리하고 웨일 웹 콘텐츠에 별도 전달하는 **웨일 MV3 확장앱 + 설치형 Windows 로컬 프로그램**이다.

## 2. 교육 현장 사용자 시나리오

**최초 한 번**: 교사 또는 관리자 Windows 구성요소 설치 → 웨일 확장 설치/연결 승인 → Windows 확장 모드 및 전자칠판 USB 터치 연결 확인. 필요시 Windows 터치 디스플레이 매핑 안내(수동 영역 드래그가 아님).

**매 수업**: 교사가 사이드바의 `[학생 독립 터치 켜기]` 누름 → 프로그램이 모니터 2/장치/보호/Whale 연결 상태 확인 → 모두 통과하면 `ACTIVE` → 학생은 전자칠판의 웨일 웹페이지 터치, 교사는 모니터 1에서 마우스·키보드 사용 지속 → 교사가 `[끄기]` → 기본 Windows 터치 복원.

**일시적인 교사 판서/비지원 앱 이용**: `[교사 일시 해제]`로 일반 Windows 터치 복귀. 이 상태에서는 학생 독립 보호가 **비활성**임을 명확히 설명. `[독립 터치 다시 켜기]`로 장치/보호 검증을 다시 실행한다.

## 3. 지원 대상

- 단일 Windows 10/11 x64 PC, 모니터 1 + 확장 모드 모니터 2(전자칠판).
- Windows가 장치 출처/모니터 매핑을 확인할 수 있는 터치 장치(모든 제조사 100%는 미보장).
- 모니터 2의 **Whale 일반 HTTP(S) 웹페이지**: 클릭·스크롤·드래그·입력·페이지 이동, 호환이 입증된 경우 멀티터치.
- 웨일 확장 **사이드바 UI**를 통한 시작·중지·복구·진단 안내.
- 학생용 별도 주소·이동·탭 UI(실제 브라우저 기본 크롬 UI에 별도 포인터로 클릭하는 기능은 아님).
- 서버 없는 로컬 우선 실행. 민감한 이벤트 원문/키 입력/URL 로깅 금지.

## 4. 첫 버전에서 지원하지 않는 대상

- 모든 Windows 앱에서 별도 포커스/독립 커서 제공(파워포인트, 그림판, 파일 탐색기 등의 독립 터치 자동 지원 X).
- Whale 본래 탭바·주소창·사이드바·시스템 파일 대화상자를 마우스 2로 직접 누르기.
- `whale://`, `chrome://` 등 보호/내부 페이지에서 CDP 웹 조작 보장.
- 화면 복제 모드에서 별도 모니터 2를 정확히 선택하는 사용 흐름.
- 마우스 에뮬레이션 형태만 제공하는 전자칠판에서 드라이버 없이 장치별 격리가 가능한 것으로 전제.
- 확장앱만 설치해 시작, UIAccess 사용 목적/Windows 보안 제약 무시한 배포.

## 5. 변경 불가 UX 조건

1. **수동 영역 선택, 화면 드래그·보정 절차 없음.**
2. 사이트별 URL 등록·매 접속마다 선택·재보정 없음.
3. 학생 터치가 교사의 기존 Windows 커서를 움직인 뒤 복원하는 동작 절대 금지.
4. 교사 실제 마우스는 모니터 1과 2 어디든 자유롭게 이동.
5. 학생 입력은 교사 OS 키보드 포커스를 변경하지 않음.
6. 터치 장치를 안전하게 자동 판정하지 못하면 `ACTIVE` 거부 및 이유/해결 방법 제공.
7. 보호가 실제로 끊기면 `LOST_PROTECTION`; 단순 연결 지연은 `SAFE_HOLD`(격리 생존 조건)로 정확히 구분.
8. 코드가 빌드됐다는 이유만으로 **G1 성공이라고 표시하지 않음**.

## 6. 성공 판정 기준

**G1 필수 합격:** 실제 칠판에서 교사 커서·실제 키보드 포커스·타이핑 변경 0건(지정된 시험 범위 안에서), 교사 실마우스 자유 이동. 저수준 좌표 훅이나 커서 복원은 금지.

**G2 필수 합격:** 실제 지원 웹페이지에 터치 클릭·드래그·한글 입력·탭 이동이 낮은 지연으로 도달하고, 학생용 탐색 UI로 사이트 전환하며, 교사 타이핑을 방해하지 않음.

**운영 필수 합격:** 지원되는 장치에서 최초 설치 이후 일상 사용은 사이드바 ON/OFF만으로 가능. 자동 실패 판정과 복구 수단이 존재.
