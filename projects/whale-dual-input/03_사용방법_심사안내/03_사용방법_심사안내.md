# [제출물 03] 사용 방법 및 심사위원용 평가 안내서

> **기획 초안 안내 (2026-10-07):** 아래는 구현 후 목표 사용 흐름이며 현재 실행 가능한 기능 안내가 아닙니다. 현재 확장앱 루트는 `02_제작_결과물/`이고, 이 문서의 `extension/` 하위 폴더·`WhaleDualInput.exe`·시뮬레이션·F9·독립 입력은 아직 구현되지 않았습니다. 구현 순서와 시험 기준은 [구현 계획 v4](../01_기획_및_지침/whale_dual_input_implementation_plan_v4.md)를 따르며, 실제 배포 구조 확정 후 이 안내서를 갱신합니다.

> **작품명:** 웨일 듀얼 인풋 (Whale Dual Input)  
> **출품 분야:** [분야 1] 수업 지원 · 학습 활동

---

### 1. 프로그램 실행 및 준비 (초간단 2단계)

별도의 복잡한 드라이버 설치나 회원가입 없이, **실행 파일 1개와 웨일 브라우저만으로 즉시 작동**합니다.

#### 1단계: 웨일 브라우저 확장 프로그램 로드
1. **네이버 웨일 브라우저** 실행 후 주소창에 `whale://extensions` 입력
2. 우측 상단 **[개발자 모드]** 켜기
3. 좌측 상단 **[압축해제된 확장앱 로드]** 클릭 후 `02_제작_결과물/extension` 폴더 선택
   *(웨일 브라우저 내 가상 키보드 및 독립 터치 리시버가 준비됩니다)*

#### 2단계: 웨일 듀얼 인풋 제어창(컨트롤러) 실행
1. `02_제작_결과물/WhaleDualInput.exe` 실행
2. 화면에 **[웨일 듀얼 인풋 컨트롤러]** 제어창이 뜹니다.
3. 대상 웨일 브라우저가 자동 감지됩니다.

### 2. 심사위원 핵심 체험 시나리오 (3분 퀵 테스트)

> **💡 전자칠판이 없는 환경(일반 노트북/PC)에서도 심사 가능:**  
> 터치 지원 노트북(LG 그램 360, 갤럭시북 360 등) 또는 서브 터치 모니터 환경에서도 동일하게 테스트할 수 있으며, 제어창의 `[시뮬레이션 모드]`를 켜면 마우스 우클릭을 칠판 터치로 간주하여 1대의 일반 PC에서도 완벽히 검증 가능합니다.

#### [시나리오 단계]
1. **교사 작업 시작:**  
   모니터 좌측에 메모장(또는 한글, PPT)을 켜고 키보드로 문장을 연속으로 타이핑합니다.
2. **독립모드 활성화:**  
   제어창에서 **`[웨일 브라우저 독립모드 ON]`** 버튼을 클릭합니다.
3. **학생 전자칠판 조작 (동시 입력 테스트):**  
   전자칠판(또는 터치 화면)에 띄워진 웨일 브라우저 화면을 터치하여 웹페이지를 스크롤하고, 검색창을 터치합니다.
   - 웹페이지 하단에 **터치 전용 가상 키보드**가 자동으로 팝업됩니다.
   - 가상 키보드로 한글 단어(예: "세종대왕")를 칠판에서 터치해 입력합니다.
4. **결과 확인 (독립성 검증):**  
   - 학생이 칠판을 터치하고 글자를 입력하는 동안, 교사가 메모장에 타이핑 중이던 글자에 **오타나 글자 누락이 단 1개도 없는지 확인**합니다.
   - 교사의 마우스 커서가 칠판 위치로 순간이동하지 않고 **원래 자리에 그대로 머물러 있는지 확인**합니다.
5. **모드 해제:**  
   키보드에서 **`F9`** 키를 누르거나 제어창에서 `[OFF]`를 누르면 즉시 평상시 마우스 상태로 원복됩니다.

### 3. 로그인 및 권한 안내
- **로그인 여부:** ❌ 불필요 (선생님과 학생 모두 로그인 없이 즉시 사용)
- **외부 서버 통신:** ❌ 없음 (100% PC 로컬에서 안전하게 처리)
- **비상 복구:** `F9` 단축키로 언제든 즉시 시스템 제어권 정상 복귀
