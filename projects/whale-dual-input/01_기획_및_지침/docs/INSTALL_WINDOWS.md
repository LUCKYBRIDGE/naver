# Whale Dual Input 0.2.0 설치·사용

이 패키지는 Windows 제어 프로그램과 웨일 확장앱을 연결한 구현 결과물이다. 실제 Windows·전자칠판 동작 검증은 구현 이후 수행할 예정이다. 기본 대상은 Windows 10/11 x64, NAVER Whale, HDMI/USB 전자칠판이다.

현재 핵심 터치 분리 방식에는 [입력 엔진 판단](INPUT_ENGINE_DECISION.md)의 미해결 사항이 있다. 이 ZIP을 교사 입력 보호가 완성된 실사용 제품으로 취급하지 않는다.

## 설치

1. ZIP을 Windows의 고정 폴더에 풀고 폴더를 유지한다. `windows/WhaleDualInput.Host.exe`는 .NET 런타임이 포함된 실행 파일이다. SDK를 별도 설치할 필요 없다.
2. 웨일에서 `whale://extensions` → 개발자 모드 → 압축해제된 확장앱 로드 → 패키지의 **extension** 폴더를 선택한다. 실험용 p1a-probe가 아니다.
3. 확장앱 관리자에 표시된 **확장앱 ID 32자**를 복사한다.
4. `windows/WhaleDualInput.Host.exe`를 실행하고 확장앱 ID를 붙여 넣은 뒤 `현재 사용자에 연결 등록`을 누른다. 관리자 권한·자동 시작·드라이버 설치는 사용하지 않는다.
5. 등록창을 닫고 웨일 사이드바에서 프로그램을 연다. `Windows 프로그램 연결`을 누르면 별도의 Windows 제어창이 실행된다.

Native Messaging 등록 위치는 웨일 설치 버전에서 확인해야 한다. 등록창의 초기 후보는 `HKCU\Software\Naver\Naver Whale\NativeMessagingHosts`이다. 이 위치는 아직 실기기에서 확정하지 않았다. 연결 오류가 나면 확인된 웨일 경로로 등록창에서 변경한다. Chrome/Edge 등록이나 학교 정책을 자동 수정하지 않는다. 등록 해제는 동일한 경로·ID로 `연결 등록 해제`를 누른다.

## 수업 준비

1. Windows 확장 화면에서 업무 모니터와 전자칠판에 교사·학생 창을 각각 표시한다. 복제 화면에서는 두 창이 동시에 보이는 배치를 사용한다.
2. 학생용 웨일 창에서 사용할 수업 페이지를 선택하고 사이드바에 그 **사이트 주소**를 입력한다.
3. `사이트 허용 · 현재 탭 선택`을 누른다. 해당 사이트의 접근 권한만 요청하며 모든 페이지에 코드를 자동 주입하지 않는다.
4. Windows 제어창에서 같은 학생 웨일 창을 고른다. `웹페이지 영역 지정`을 누르고 **주소창·탭바·사이드바를 제외한 웹페이지 viewport**의 왼쪽 위부터 오른쪽 아래까지 물리 마우스로 드래그한다. 이 설정 작업 중에는 사용자 조작에 따라 포커스가 바뀔 수 있다. 독립 모드는 아직 OFF다.
5. 사이드바에서 `ON`을 누른다. 학생 화면의 키보드가 표시된다. 교사는 업무 창으로 직접 이동해 작업한다.

## 학생 입력

- 기본 모드는 한 손가락 클릭·드래그다. 주소창·브라우저 탭·시스템 대화상자는 대상이 아니다.
- 키보드 아래 또는 사이드바에서 스크롤 모드로 바꾸면 세로 드래그가 스크롤로 전달된다. 스크롤 모드에서도 짧은 탭은 클릭으로 전달된다.
- 일반 input/textarea를 터치한 뒤 학생 키보드를 사용한다. 한/영, Shift, 숫자, 공백, Enter, Backspace, 한글 이중모음·겹받침·받침 이동을 구현했다. 교사 Windows IME를 전환하지 않는다.
- 암호·파일·읽기 전용·비활성 입력란과 iframe·리치 편집기는 기본 지원 대상이 아니다. 입력란이 선택되지 않으면 키보드는 안내만 표시한다.
- OFF 또는 **F9**로 해제한다. Windows 제어창의 OFF와 프로그램 종료도 입력 수신 창을 닫는다.

## 자동 해제

탭 탐색·숨김·페이지 크기/배율 변경, 대상 창 이동·최소화·다른 창에 가림, USB 입력 장치 변경, 통신 끊김, 입력 큐 지연, 커서 억제가 감지되면 해제한다. 다시 사용할 때 대상 선택·영역 교정이 필요할 수 있다. 시작 상태는 항상 OFF이며 이전 ON 상태를 복원하지 않는다. UI나 통신이 멈추면 감시부가 호스트 프로세스를 종료해 입력 수신 창을 제거한다.

## 구현 범위와 남은 확인

터치 수신은 비활성 Win32 수신 창 후보를 구현했다. 물리 마우스 통과, 터치에 따른 Windows 커서 억제, 사이트별 CDP/IME 호환성, 웨일 Native 등록 위치의 실제 동작은 Windows와 전자칠판에서 확인해야 한다. 구현·컴파일 완료를 교사 입력 보호의 실증 성공으로 표시하지 않는다.

실행 파일을 다른 폴더로 옮기거나 확장앱 ID가 바뀌면 연결 등록을 다시 한다. 제거할 때 OFF → 연결 등록 해제 → 웨일 확장앱 제거 → 패키지 폴더 삭제 순서로 진행한다. 등록 해제는 이 프로그램의 호스트 키만 처리한다.

개발 PC에서 재생성: Node.js 24 이상과 .NET 10 SDK를 준비하고 저장소 루트에서 `npm run build:windows`를 실행한다. 일반 확장앱 빌드는 `npm run build`다. 테스트 코드는 패키지에 포함되지 않는다.
