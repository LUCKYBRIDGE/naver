# design.md — 웨일 듀얼 인풋 사이드바 UI 디자인 시스템

> 버전: 1.1 / 2026-10-08  
> 대상: 웨일 `sidebar_action` 교사용 제어 패널.  
> 목표: 좁은 사이드바에서 **현재 보호 상태와 단일 주 동작 버튼**이 즉시 파악되는 차분하고 명료한 UI.

## 1. 디자인 방향

- 형태: 학교 PC용 **가볍고 안정적인 유틸리티**. 화려한 대시보드·대형 배너/이미지 금지.
- 한국어로 간결하게. 기술 용어(`ACK`, `PT_TOUCH`, `HID`)는 진단 상세에만.
- 상태를 색상으로만 전달하지 않음. 정밀한 시스템 상태를 숨기지 않음.
- 사용자 행동은 한 번에 하나: OFF에서는 `학생 독립 터치 켜기`, ACTIVE에서는 `끄기`.
- 중요한 경고는 접히거나 사라지는 토스트에만 두지 않음.
- '모니터 2 자동 인식'은 안내 문구이지 검증되지 않은 상태에서 항상 '연결됨'을 뜻하지 않음.

## 2. 정보 구조

```text
[header] 제품 아이콘 | 웨일 듀얼 인풋 | 도움말
[status panel] 상태 아이콘 + 제목 / 1줄 설명
[connection card] 모니터 2 / 전자칠판 터치 / 학생용 웨일
[primary CTA] ON 또는 OFF 또는 다시 확인
[conditional action] 교사 일시 해제 / 다시 연결 / 복구
[context hint] 지원 범위 및 영역 수동 지정 없음
[accordion] 문제 해결 · 진단 보기
[footer] 로컬 동작 · 초기 설치 안내
```

## 4. 규격

- 사이드바 기준 폭: `width:100%; min-width:0`, 권장 검증 300/320/360/400/480px. 브라우저 확대 125%, 150%, 200%도 시험.
- 화면 높이: 브라우저 세로 길이 변화에 대응하는 스크롤형 레이아웃. **버튼/경고가 화면 밖으로 잘리는 고정 높이 금지**.
- 바깥 패딩 16px, 카드 패딩 14~16px, 카드 간격 12px, 섹션 간격 16px.
- 둥근 모서리 12~16px, 선 두께 1px, 그림자 최소.
- 제목 18px/700, 상태제목 16px/700, 본문 14px/400, 부연 12~13px/400.
- 조작 요소 최소 높이 44px. 상태별 중복 버튼·토글 2개 금지.
- 시스템 글꼴: `system-ui, -apple-system, 'Malgun Gothic', sans-serif`.
- 상태 강조색은 **하나의 가장 중요한 상태**에만 집중. 일반 카드에 배지 남발하지 않기.

## 5. 컴포넌트 명세

### Header
- 제품명은 말줄임 없이 한 줄 또는 두 줄 허용. 도움말 버튼은 키보드 접근 가능.

### StatusPanel
- `icon + title + copy`, 상태 코드 자체는 일반 화면에 보여주지 않음.
- `LOST_PROTECTION`은 붉은 바탕+아이콘+텍스트 경고, 전체 페이지 뒤덮는 팝업 금지. 교사에게 즉시 노출.
- 스크린리더 상태 발표: `aria-live="polite"`; 위험 상태의 별도 문구 `role="alert"`.

### ConnectionList
- 3개 행 고정(모니터/전자칠판 터치/학생 웹). 실제 측정/연결 결과만 표시.
- 연결 실패 항목에 사유와 도움말 링크 부착. 쓸데없는 '100%' 진행률 금지.

### PrimaryButton
- 너비 100%, 44px 이상, 두드러진 대비. OFF → 켜기; ACTIVE → 끄기; SAFE_HOLD → 다시 연결 확인; UNSUPPORTED → 다시 확인.
- 클릭 연타 잠금, 진행 중 버튼 로딩/비활성; Native ACK 후 상태 확정.
- `LOST_PROTECTION`에서 재시작 버튼은 실패 상황을 무시하고 ACTIVE로 강제 전환해서는 안 됨.

### SecondaryActions
- ACTIVE: `교사 일시 해제`는 경고 확인 후만 실행.
- 오류/설치: `설치 방법 보기`, `진단 보기`.
- 보조 기능은 주 CTA보다 시각적으로 약하게.

### DiagnosticsAccordion
- 펼침 기본값 false. 오류 시에도 화면은 요약과 해결 방법 먼저.
- 진단 내용 복사는 기기 ID 전체·사용자 문서·URL·학생 글자를 배제.

## 6. 화면 예외

1. **Native 설치 전**: 문구 `Windows 구성요소 설치 필요`, 설치 방법과 `다시 확인`; 가짜 ON 버튼 표시 금지.
2. **모니터 2 없음**: `두 번째 화면을 연결하세요`; 창 위치를 교사가 드래그해 표시 구역 지정하는 우회 방안 금지.
3. **화면 복제**: Windows 확장 모드 설정을 안내; ACTIVE 금지.
4. **학생 웨일 탭 없음**: `모니터 2에서 웨일 웹페이지를 열어주세요`; 포커스를 빼앗는 강제 창 활성화 금지.
5. **보호 상실**: `터치를 중단하세요` 명확히 표기; watchdog만으로 보호 보증하지 않음.
6. **일반 Windows 앱 터치**: 지원되지 않는다는 점을 학생 화면에 포커스 훔침 없이 알림(구현 가능 여부 검증); 교사 OS 클릭으로 대체 금지.
7. **권한 정책 문제**: UIAccess 목적/서명/정책 문제가 해결되지 않으면 진단 내용과 미지원 상태를 표시.

## 7. 움직임과 접근성

- 선택된 탭, 포커스 링 명확히. 키보드 `Enter`/`Space` 액션 가능.
- 애니메이션은 120–180ms 단순 전환, 로딩은 필요할 때만. `prefers-reduced-motion`이면 제거.
- 모든 설명과 버튼은 200% 확대 시 글자 겹침/잘림 없어야 함.
- 라이트/다크 모두 텍스트 4.5:1 이상 목표(검증 필수).

## 8. 시연용 목업과 실제 구현 구분

`../../../Whale_Dual_Input_Development_Handoff_v1_1/06_mockup/index.html`은 순수 HTML/CSS/JS **시각 데모**이며, 상태 선택으로 화면이 어떻게 변하는지 확인하는 용도다. 실제 Whale/Native/Tier A/B를 실행하지 않는다. 제품에서는 데모 전용 상태 선택 UI를 제거하고 백엔드의 실측 상태로만 렌더한다.
