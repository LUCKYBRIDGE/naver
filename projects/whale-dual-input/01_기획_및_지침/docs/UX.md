# 사용 흐름 계획

작성일: 2026-10-07. 상태: 설계, UI 구현 전.

## 첫 준비

교사는 확장앱과 로컬 호스트를 준비하고 실제 터치 장치·전자칠판 화면·학생 웨일 창을 연결한다. Native 등록과 좌표 교정은 첫 준비에서 처리한다. 이후 매 수업에서 설치 절차를 반복하지 않도록 한다.

복제 환경은 웨일과 업무 창이 함께 보이는 배치, 확장 환경은 각 화면의 별도 창 배치를 안내한다. 학생 화면을 보이게 하려고 교사 작업 창을 강제 활성화·최소화하지 않는다.

## 수업 시작

1. 교사가 학생 대상 웨일 창·탭을 선택한다.
2. 사이드바에서 연결·터치 장치·대상 준비 상태를 확인한다.
3. 준비되면 독립모드 ON. 교사는 원하는 업무 창으로 직접 돌아가 계속 작업한다.
4. 다음 실행은 검증된 대상 설정을 표시하고 ON 1회로 시작하는 흐름을 목표로 한다. 대상 소실·재연결은 다시 확인한다.

첫 화면 문구는 “교사는 하던 일을 계속하고, 학생은 이 웨일 창을 조작합니다”를 중심으로 쓴다. ON/OFF·준비 상태·짧은 오류 안내를 우선 표시한다. 디버깅 메서드·장치 코드·긴 기술 설명은 일반 사용 흐름에 노출하지 않는다.

## 학생 조작

학생은 전자칠판에서 링크·버튼을 누르고 스크롤·드래그한다. 입력란을 선택하면 페이지 내부 가상 키보드가 나타나 한글·영문·숫자를 입력한다. 필요하면 학생용 표시 포인터로 위치를 확인한다. 학생은 Windows 주소창·시스템 대화상자를 조작하지 않는다.

교사 커서·입력 대상과 학생 페이지 편집 대상을 구분한다. 학생의 한/영·Shift·삭제가 교사 문서에 영향을 주지 않아야 한다.

## 오류와 종료

| 상태 | 짧은 안내 | 다음 행동 |
|---|---|---|
| 로컬 호스트 없음 | 연결 프로그램을 실행해 주세요 | 실행·등록 안내 열기 |
| 터치 장치 구분 불가 | 전자칠판 입력을 확인할 수 없습니다 | 장치·터치 매핑 확인, ON 비활성 |
| 좌표·대상 변경 | 대상 화면을 다시 확인해 주세요 | 재선택·교정 |
| 지원하지 않는 입력란 | 이 입력란은 아직 지원하지 않습니다 | 키보드 닫기·다른 지원 입력란 사용 |
| 연결 종료·F9 | 독립모드가 해제되었습니다 | 필요 시 연결 확인 후 다시 ON |

OFF와 F9는 즉시 일반 입력으로 돌아가는 수단이다. 연결 장애도 세션을 종료한다. 키보드에는 닫기·취소를 제공하고 실제 입력이 되지 않았는데 성공 표시를 하지 않는다.

## 접근성·성능

390px 사이드바 한 열, 폭 변경·큰 글자 대응, 주요 버튼 텍스트와 충분한 터치 영역, 키보드 조작, 색상 외 상태 표시를 기본으로 한다. 숨겨진 사이드바의 반복 UI 작업은 중단하고 독립 입력 세션은 호스트와 Worker의 상태로 관리한다.
