# 구현 준비 체크리스트

작성일: 2026-10-07. 기준 계획: [구현 계획 v4](../whale_dual_input_implementation_plan_v4.md).

## 1. 이번에 완료한 준비

- [x] 현재 Manifest와 전체 프로젝트 문서·코드 확인.
- [x] 교사 입력 보호와 학생 웨일 내부 입력이라는 요구사항 확정.
- [x] Windows 격리와 비활성 웨일 입력 전달을 별도 검증 과제로 분리.
- [x] 실제 화면 복제·확장에 따른 표시 제약 기록.
- [x] Native Messaging·CDP·입력 수신 창 후보와 실패 시 판단 기준 작성.
- [x] 개발 도구 존재 여부를 읽기 전용 명령으로 확인.
- [x] 테스트·개인정보·UX·기획 문서 작성.

이번 준비에는 브라우저 설치, SDK 추가 설치, 호스트 등록, 후크 실행, 디스플레이 설정 변경, exe 생성이 포함되지 않는다.

## 2. 개발 PC 관찰 결과

| 항목 | 확인한 값 | 의미 / 다음 준비 |
|---|---|---|
| OS | Windows 11 Home, 10.0.26200, 64비트 | 현재 개발 PC 값. 학교 PC와 동일하다고 가정하지 않음 |
| .NET SDK | 8.0.424 | 설치 확인. 생산 후보 .NET 10 SDK는 아직 미확인 |
| Node.js | v24.15.0 | 기존 JS 스크립트와 향후 순수 모듈 검사에 사용 가능 |
| Python | 실행 경로 존재 | 문서 검사 보조. Native 실행 의존성으로 추가하지 않음 |
| rg | 실행 경로 존재 | 코드·문서 검색 가능 |
| Whale | 실행 프로세스, 검사한 일반 설치 경로·레지스트리에서 확인되지 않음 | 설치되지 않았다고 단정하지 않음. 실제 실행 파일과 버전 확인 필요 |
| 전자칠판 / USB 터치 | 미확인 | 제조사·모델·장치 매핑 확인 필요 |
| 화면 구성 | 미확인 | 복제/확장, 화면 번호·해상도·배율 기록 필요 |
| 버전 관리 | 현재 workspace에서 Git 저장소 확인되지 않음 | 첫 구현 전 변경 이력을 남길 저장소 또는 별도 백업 준비 |

도구 버전은 2026-10-07 관찰값이며 실제 수업 환경의 확인 결과가 아니다. .NET 10 LTS는 2028-11-14까지 지원하고 .NET 8 지원은 2026-11-10 종료 예정이므로 생산 버전은 .NET 10을 우선 평가한다. SDK 설치는 첫 구현 준비 시 수행한다. [Microsoft 지원 정책](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)

## 3. 실제 환경 기록표

현재 빈칸은 기술 검증 전에 채운다. 비밀번호·학생 실명·학교 계정 정보는 기록하지 않는다.

| 확인 항목 | 현재 값 | 준비 방법 |
|---|---|---|
| 전자칠판 제조사·모델 | 미확인 | 모델명 확인 |
| 연결 방식 | 미확인 | HDMI/DP와 USB 터치 연결 구분 |
| 전자칠판 자체 OS 사용 여부 | 대상 아님 | 교사 PC의 외부 화면 모드로 시험 |
| USB 터치의 Windows 인식 방식 | 미확인 | HID 터치/펜/일반 마우스 및 장치 식별 가능성 관찰 |
| 교사 PC Windows 버전·빌드 | 미확인 | 학교 시험 PC에서 확인 |
| 화면 복제/확장 | 미확인 | Windows 디스플레이 설정에서 확인 |
| 각 화면 해상도·배율·방향 | 미확인 | 100/125/150% 등 혼합 DPI 포함 |
| 전자칠판 터치 화면 매핑 | 미확인 | 터치가 실제 표시 화면에 대응하는지 확인 |
| Whale 버전·내부 Chromium 버전 | 미확인 | Whale 버전 정보에서 기록 |
| 확장앱 ID·Native 호스트 등록 방식 | 미확인 | 개발 로드와 배포 ID를 구분, Whale에서 실증 |
| 학교 확장앱·exe·호스트 정책 | 미확인 | debugger·Native 호스트 사용 가능 여부 확인 |
| 첫 실제 테스트 사이트 | 미확인 | 시험 페이지 통과 후 공개 페이지, 이후 수업 사이트 |

다른 터치 기기나 펜이 함께 연결된 환경도 한 번 확인한다. 터치 서명만으로 전자칠판을 특정하지 않는다.

## 4. 필요한 준비물

- 교사 작업용 물리 마우스·키보드와 입력 확인용 메모장. 이후 한글/PPT/다른 웨일 창으로 확대.
- 실제 PC 외부 디스플레이 모드의 전자칠판과 USB 터치 연결.
- NAVER Whale과 개발자 모드 확장앱 로드 가능 환경.
- Native 호스트 등록·제거가 가능한 시험 사용자 계정. 관리자 권한 없이 가능한 범위를 우선 확인.
- 한글 조합·마우스 드래그를 함께 수행할 두 명의 시험자. 한 사람이 순차 조작한 결과를 동시성 시험으로 기록하지 않음.
- 알려진 시험 문장과 페이지. 실제 학생 데이터·업무 문서를 사용하지 않음.
- 커서 숨김·짧은 포커스 변화 확인용 관찰 도구. 필요 시 개인정보 없는 시험 화면만 수동 영상 기록.

터치 노트북은 예비 실험에 쓸 수 있으나 실제 USB 전자칠판 합격을 대신하지 않는다. 일반 마우스 우클릭 시뮬레이션은 UI·통신 확인용이다.

## 5. 첫 구현 순서

1. 개발 이력·백업과 실제 Whale 실행 경로 확보.
2. 학교 대상 OS를 확인하고 .NET 10 SDK 및 Win32 개발 참조 준비. 기존 프로젝트에 대형 프레임워크나 JS 빌드 체계를 먼저 추가하지 않음.
3. 시험 페이지와 CDP 프로브 작성. 물리 터치 없이 비활성 웨일 입력 전달을 확인.
4. Native 관찰 프로브 작성. 차단 없이 터치·마우스·포인터·커서 상태를 관찰.
5. F9·프로세스 종료 시 해제부터 구현하고 A/B 격리 프로브 시험.
6. [TEST](TEST.md)의 P1a/P1b 결과를 기록한 후 Native 연결과 세션을 구현.
