# [제출물 01] 기획의도 1페이지

---

### 1. 작품 개요
* **작품명:** **웨일 듀얼 인풋 (Whale Dual Input)** — 전자칠판-교사 동시 독립 수업 도구
* **출품 분야:** **[분야 1] 수업 지원 · 학습 활동**
* **연계 서비스:** **웨일 클래스 (Whale Class)**, **웨일 팀보드 (Team Board)**, **웨일온 (Whale ON)**

---

### 2. 해결하려는 문제 (Problem)
* **교실의 현실:** 대부분의 교실에서 전자칠판은 교사 PC 화면을 그대로 비추는(복제/확장) 형태로 사용되며, 터치는 USB 케이블을 통해 Windows로 전달됩니다.
* **치명적인 입력 충돌:** Windows는 전자칠판의 터치를 **"PC의 유일한 마우스(System Cursor)"**로 자동 변환합니다. 이로 인해 학생이 전자칠판에서 팀보드나 웨일 클래스 화면을 터치하는 순간, **교사의 마우스 커서가 칠판으로 강제 이동**하고 교사가 작업 중이던 창(한글, PPT, 관찰 기록 등)의 **키보드 포커스가 강제로 해제**됩니다.
* **수업의 단절:** 결국 "학생이 칠판을 쓸 때는 교사가 PC를 멈춰야 하고, 교사가 PC를 쓸 때는 학생이 칠판을 만지지 못하는" 반쪽짜리 스마트 교실이 되고 맙니다.

---

### 3. 핵심 기능 (Solution & Key Features)
1. **전자칠판 터치-교사 마우스 OS 레벨 원천 분리 (Hardware Filtering)**
   * Windows 저수준 입력 훅(`WH_MOUSE_LL`)을 통해 전자칠판의 터치 서명(`dwExtraInfo & 0xFF515700`)을 실시간 감별합니다.
   * 독립모드가 켜진 웨일 창 영역의 터치는 시스템 마우스 이동을 **원천 차단(`return 1`)**하여 교사 커서의 튐과 커서 숨김을 0%로 만들고, 오직 해당 웨일 창 내부의 클릭·스크롤 이벤트로만 직결 전달합니다.
   * 교사의 물리 마우스는 0ms 지연으로 평소와 동일하게 모니터 어디든 자유롭게 사용합니다.

2. **웹페이지 내장형 터치 가상 키보드 (In-Page Virtual Keyboard & Composer)**
   * 학생이 전자칠판에서 웨일 내 검색창이나 입력란을 터치하면 웹페이지 내부(Shadow DOM)에 터치 전용 가상 키보드가 팝업됩니다.
   * 자체 한글 음소 조합기를 탑재하여 학생의 글자 입력을 완성하며, Windows OSK나 `SendInput`을 일절 쓰지 않아 교사의 키보드 타이핑에 학생 글자가 단 1자도 섞이지 않습니다.

3. **교사용 원클릭 전용 제어창 (Teacher Control Center)**
   * **`[독립모드 ON / OFF]`** 대형 토글 스위치와 실시간 차단 카운터, 비상 해제 단축키(`F9`)를 제공하여 선생님이 언제든 1초 만에 일반 마우스 모드와 독립 수업 모드를 전환할 수 있습니다.

---

### 4. 기대 효과 및 웨일 연계성 (Impact)
* **수업 루틴의 획기적 개선 (진정한 1인 1기기 + 1대 교사 PC 협업):**
  학생이 전자칠판에서 웨일 팀보드로 모둠 발표 자료를 정리하고 검색하는 동안, 교사는 같은 PC에서 다음 차시 준비, 학생 관찰 기록, 웨일 클래스 과제 피드백을 동시에 수행할 수 있습니다.
* **웨일 교육 서비스와의 완벽한 시너지:**
  웨일 브라우저 기반의 팀보드, 클래스, 퀴즈 도구들이 전자칠판에서 완전한 '독립 인터랙션 스테이션'으로 진화합니다.
* **전국 모든 교실에 즉시 적용 가능한 압도적 범용성:**
  고가의 추가 하드웨어나 OS 교체 없이, 전국 초·중·고에 이미 보급된 일반 Windows PC와 전자칠판 환경에서 실행 파일 하나로 즉시 작동합니다.
