## 🔒 격리 및 개발 원칙
1. 이 프로젝트의 모든 소스코드는 `02_제작_결과물/` 내부에만 작성합니다.
2. 교사의 물리 마우스와 키보드 입력을 보호합니다. 커서 이동·숨김, 포커스 탈취, 입력 누락을 허용하지 않으며 지연은 실제 측정으로 검증합니다.
3. 전자칠판 터치는 지정된 웨일 창 내부에서만 독립 마우스/키보드로 동작합니다.
