## 2. 필수 검증 체크리스트

### 1) 설치 및 로드
- [ ] `whale://extensions`에서 '압축해제된 확장앱 로드' 시 에러나 경고 팝업 없이 로드되는가?
- [ ] 16x16, 48x48, 128x128 아이콘이 웨일 사이드바 툴바와 관리자 페이지에 깨짐 없이 표시되는가?
- [ ] Service Worker 상태가 '활성(Active)'으로 정상 표시되는가?

### 2) 웨일 사이드바 동작
- [ ] 사이드바 버튼 클릭 시 지연 없이 즉시 UI가 열리는가? (체감 0.5초 이내)
- [ ] 사이드바 너비를 최소 폭(약 390px)으로 좁혔을 때 가로 스크롤 없이 모든 내용이 표시되는가?
- [ ] 사이드바 너비를 최대 폭(약 590px)으로 넓혔을 때 여백과 배치가 자연스러운가?
- [ ] 사이드바를 닫았을 때 `visibilitychange` 이벤트가 발생하여 유휴 상태로 전환되는가?

### 3) 웹페이지 Content Script 상호작용
- [ ] 네이버 뉴스, 위키백과, EBS, 엔트리 등 대표적인 교육 사이트에서 정상 작동하는가?
- [ ] 확장앱의 CSS 스타일이 호스트 페이지의 폰트나 레이아웃을 변형시키지 않는가?
- [ ] `whale://` 또는 `chrome://` 내부 페이지에서 버튼 클릭 시 크래시나 무한 루프 없이 적절한 안내가 나오는가?

### 4) 데이터 및 Local-First 저장
- [ ] 새 메모를 저장한 후 브라우저 탭을 닫거나 재시작해도 데이터가 유지되는가?
- [ ] 메모 삭제 시 즉시 목록에서 제거되고 스토리지에서도 삭제되는가?
- [ ] 외부 서버로 무단 네트워크 패킷(Fetch/XHR)이 발생하지 않는가? (개발자도구 네트워크 탭 확인)

### 5) 프로그램 통합(Merge) 검증 (03-unified-edu-suite)
- [ ] 상단 탭 전환 시 '학습 메모'와 '읽기 가이드' 패널이 매끄럽게 전환되는가?
- [ ] 두 기능이 활성화된 상태에서도 상호 간섭이나 이벤트 충돌이 발생하지 않는가?
