# 개인정보 및 권한 정책 (PRIVACY.md)

> 학생 데이터 보호와 웨일 스토어 심사 통과를 위한 권한 및 데이터 처리 정책 문서입니다.

---

## 1. 기본 원칙
> **"불필요한 학생 데이터는 수집하지 않으며, 모든 학습 데이터는 기기 로컬에만 안전하게 보관합니다."**

---

## 2. 매니페스트 권한(Permissions) 명세 및 정당성

| 권한 명칭 | 요청 사유 | 심사 정당성 설명 |
| :--- | :--- | :--- |
| `storage` | 학습 메모 및 사용자 설정 저장 | 외부 서버 없이 브라우저 내부에만 안전하게 상태를 보관하기 위해 필수적입니다. |
| `activeTab` | 현재 페이지 제목, URL 및 드래그 텍스트 읽기 | 사용자가 명시적으로 사이드바를 열거나 버튼을 눌렀을 때에만 현재 탭의 텍스트를 읽기 위한 최소 권한입니다. (`<all_urls>` 대체) |

---

## 3. 데이터 수집 및 전송 정책

- **학생 개인정보 수집 여부:** ❌ 수집하지 않음 (이름, 학번, 이메일, 학교명 등 일체 요구하지 않음)
- **외부 서버 전송 여부:** ❌ 전송하지 않음 (네트워크 호출 없음, Local-first)
- **방문 기록/검색 기록 수집:** ❌ 수집하지 않음
- **데이터 보관 위치:** 브라우저 내부 `whale.storage.local`
- **데이터 삭제 방식:** 사이드바 내 [삭제] 버튼 클릭 시 즉시 로컬 스토리지에서 영구 제거

---

## 4. 학교 및 교실 환경 고려사항
- 웨일스페이스 조직 관리자가 일괄 배포 시 별도의 회원가입이나 계정 인증 절차 없이 즉시 동작합니다.
- 공용 PC 환경에서도 브라우저 세션 및 사용자 프로필 단위로 데이터가 격리됩니다.
